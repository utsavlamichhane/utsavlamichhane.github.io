What is mbX Pro?

A complete, fully documented 16S amplicon analysis pipeline — from raw reads to a publication-ready report.

01What is mbX ProThe pipeline, in brief 02How to use itSetup & workflow 03Algorithms in mbX ProAll documented steps

mbX Pro is an end-to-end workflow for 16S rRNA amplicon data. It chains together every stage of a modern microbiome study — primer detection, denoising, taxonomy, diversity, differential abundance, functional prediction, machine learning and network analysis — into 19 ordered, reproducible steps.

Each step is documented as its own reference page with copy-ready commands and a companion slide deck, so an analysis runs the same way on any machine and is easy to teach, audit and reuse.

19

Nineteen steps

A guided path from raw FASTQ to final report — nothing skipped, every decision documented.

Q2

Built on QIIME 2

A standalone pipeline tool that wraps QIIME 2 with sensible defaults and clear, copy-ready commands.

✓

Reproducible

Same inputs, same outputs — designed for HPC environments like UGA's Sapelo2.
